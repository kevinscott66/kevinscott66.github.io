Конфиденциальность и права

Обновлено 26 октября 2026 года

Слойра — демонстрационный редактор SVG-иллюстраций на dobropalm.tech. Администратор сайта — Павлович Александр Кириллович. Для обращений: hello@dobropalm.tech.

Что происходит с вашими файлами

Описание картинки, загруженные SVG, проекты и наборы цветов обрабатываются в вашем браузере. Редактор не отправляет их на сервер или в сервисы искусственного интеллекта.

Текущая композиция хранится в памяти открытой страницы. После перезагрузки она не восстанавливается автоматически. Кнопки «Сохранить» и «Скачать» создают файлы на вашем устройстве; эти файлы остаются у вас.

Посещение сайта

В редакторе нет регистрации, форм обратной связи, рекламных и аналитических счётчиков. Он не использует cookies или постоянное хранилище браузера для сохранения ваших действий. Браузер может кэшировать файлы самого сайта.

Сайт размещён на GitHub Pages. При посещении GitHub сохраняет IP-адрес для обеспечения безопасности, даже если вы не вошли в аккаунт GitHub. Подробнее — в документации GitHub Pages.

Иллюстрации

Встроенные иллюстрации предоставлены в Figma для тестового задания Студии Очень / Снэпбилд. Они не являются авторской графикой dobropalm и не входят в MIT-лицензию кода портфолио.

Иллюстрации используются для демонстрации выполненного задания. Возможность скачать картинку не предоставляет отдельного разрешения на коммерческое использование исходной графики. Права на файлы, которые вы добавляете сами, остаются у их правообладателей.

Вопросы о работе редактора, конфиденциальности и правах на материалы можно отправить на hello@dobropalm.tech. Если вы пишете по почте, ваш адрес и текст письма обрабатываются почтовыми сервисами для доставки и ответа.
