# Слойра

Конструктор векторных иллюстраций из готовых SVG-предметов. Выполнен как тестовое задание для Студии Очень / Снэпбилд.

[Открыть редактор](https://dobropalm.tech/demos/svg-studio/) | [Проект в портфолио](https://dobropalm.tech/ru/#sloyra)

![Интерфейс редактора](preview.png)

## Как проверить

1. Введите «Музыка и отдых» и нажмите «Собрать»: редактор подберёт предметы по теме.
2. Попробуйте задать расположение: «Лампа слева, книга по центру, растение справа». Редактор разместит три предмета в указанном порядке.
3. Выберите предмет на холсте или в списке «Предметы». В панели настроек переключите «Главный / Фоновый» и исходник S/L. Это варианты исходной графики; порядок наложения задаётся отдельно. Переместите предмет, измените его масштаб за угол рамки или поверните за верхнюю ручку. На сенсорном экране доступны перемещение одним пальцем, поворот и масштабирование двумя.
4. В списке «Предметы» перетащите строку, чтобы изменить порядок слоёв. Проверьте копирование и удаление выбранного предмета.
5. Смените размер холста и палитру. В разделе «Дополнительно» можно загрузить SVG, палитру и ранее сохранённый проект.
6. Нажмите «Скачать SVG»: результат — редактируемый `composition.svg`. «Сохранить проект» выгружает `composition-project.json` для продолжения работы в редакторе. На мобильном устройстве браузер может открыть файл в отдельной вкладке; тогда используйте «Поделиться → Сохранить в Файлы».

Три готовых примера доступны в SVG и JSON:

| Композиция | Изображение | Проект для открытия в редакторе |
| --- | --- | --- |
| Учёба | [learning.svg](examples/learning.svg) | [learning.json](examples/learning.json) |
| Музыка | [music.svg](examples/music.svg) | [music.json](examples/music.json) |
| Финансы | [finance.svg](examples/finance.svg) | [finance.json](examples/finance.json) |

## Реализация требований

- **Библиотека и импорт SVG.** Использованы предоставленные иллюстрации: 10 предметов с вариантами S/L и основной/фоновой ролью, всего 40 файлов. Можно загрузить собственный SVG в пределах поддерживаемого набора элементов.
- **Два сценария подбора.** По теме или метафоре из словаря и по названиям предметов. Поддержаны количества, синонимы, простые опечатки, исключения и расположение объектов.
- **Редактор композиции.** Общий холст, перемещение, поворот, пропорциональный масштаб, копирование, удаление и порядок слоёв. Можно смешивать предметы из разных исходных иллюстраций.
- **Размер и цвет.** Три размера холста, переключение исходных вариантов размера S/L, три встроенные цветовые схемы и загрузка палитры JSON с перекраской композиции. Цвета фона допустимы в предметах; цвета предметов не предлагаются для фона. Основные и фоновые варианты доступны отдельно.
- **Векторный экспорт.** SVG сохраняет предметы отдельными векторными группами. Растр не используется; рамка выделения, ручки и водяной знак превью в экспорт не попадают. Новые изображения не генерируются.

## Локальный запуск

Скачайте репозиторий или клонируйте его:

```sh
git clone https://github.com/kevinscott66/sloyra.git
cd sloyra
python3 -m http.server 8768 --bind 127.0.0.1
```

Откройте [localhost:8768](http://127.0.0.1:8768). Python 3 нужен только для раздачи файлов. Сборка, npm-зависимости, регистрация и API-ключи не нужны.

## Архитектура

Это статическое приложение на HTML, CSS и JavaScript. Обработка описаний и файлов происходит в браузере; пользовательские файлы не отправляются на сервер.

| Файл | Назначение |
| --- | --- |
| `assets/library.json`, `assets/*.svg` | Каталог с названиями, тегами и ссылками на варианты предметов; исходная графика хранится отдельно от кода. |
| `engine.js` | Каталог, подбор по темам и названиям, палитры и общие правила состояния. |
| `composition-agent.js` | Локальный разбор описания, план расположения и проверка противоречий перед изменением холста. |
| `svg-safety.js` | Разбор SVG по списку допустимых элементов и атрибутов, удаление активного содержимого и внешних ссылок. |
| `app.js` | Загрузка библиотеки, интерфейс, жесты, слои, сохранение и экспорт. |

При загрузке SVG разбираются и сохраняются в памяти браузера. Для каждого предмета создаётся отдельная группа с собственными идентификаторами и ссылками внутри SVG, поэтому один исходник можно использовать несколько раз. Перемещение, поворот и масштаб задаются преобразованием группы. Палитра меняет допустимые цвета; экспорт сериализует векторный холст без элементов интерфейса.

## Допущения и ограничения

- Подбор по метафоре реализован словарём тем и правилами. Это не обученная языковая модель и не понимание любого русского текста. Неподдерживаемые или противоречивые запросы могут потребовать уточнения; текущая композиция при этом сохраняется.
- Фраза «на столе» использует фон как поверхность и выравнивает существующие предметы. Отдельный рисунок стола не создаётся.
- Импорт поддерживает часть стандарта SVG: активное содержимое и внешние ссылки удаляются. Лимиты: 100 предметов, 2 МБ на SVG, 1 МБ на проект и 64 КБ на палитру.
- Сохранение проекта JSON доступно для встроенной библиотеки. Композицию с импортированными предметами можно экспортировать в SVG.
- Автоматические тесты и браузерные проверки не заменяют проверку жестов на физических iPhone и Android; полный аппаратный прогон не подтверждён.

## Проверки и изменение кода

Для автоматических тестов нужен Node.js 22 или новее:

```sh
node --test tests/*.test.mjs
```

Проверяются подбор, количества и расположение, состояние редактора, жесты, слои, импорт и экспорт. В набор входят 5000 комбинаций запросов; это регрессионная проверка поддерживаемых правил, а не оценка понимания произвольного языка.

После изменения CSS или JavaScript обновите хеши ресурсов:

```sh
python3 tools/sync_static_versions.py
```

## Изменения по обратной связи от 1 ноября 2026

В локальной версии автоматическая раскладка не добавляет наклон. Настройки выбранного объекта открыты в правой панели: «Главный / Фоновый» и отдельный выбор исходного SVG S/L. Размер объекта больше не зависит от размера холста и сохраняется в JSON. Иллюстрации отображаются в общем масштабе исходных координат, поэтому их относительные размеры не выравниваются в одинаковые квадраты. Ручное масштабирование остаётся доступным. Подбор по теме основан на локальном словаре, а не на LLM; подсказка в редакторе объясняет этот принцип и перечисляет выбранные предметы.
