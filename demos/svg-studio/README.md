# Слойра — редактор иллюстраций

Локальный веб-прототип конструктора иллюстраций из библиотеки тестового задания. Реализация с помощью Codex.

## Запуск

Из этой папки выполните `python3 -m http.server 8768 --bind 127.0.0.1`, затем откройте http://127.0.0.1:8768 . Установка зависимостей и API-ключи не нужны. Файлы обрабатываются в браузере, сервер только раздаёт статику.

## Демонстрация

1. Введите «Рост знаний и новые идеи», нажмите «Собрать».
2. Переключите размер на 1200 × 800: подгрузится детализация L. Выберите «Персик».
3. Перетаскивайте объекты; настройте поворот, масштаб, главную/фоновую роль и порядок слоёв. Объект можно дублировать или удалить.
4. Скачайте SVG, либо сохраните проект JSON для дальнейшего редактирования.
5. Примеры в `examples/`: learning, music, finance. Каждый представлен SVG и редактируемым проектом JSON. JSON можно открыть через «Дополнительно → Открыть сохранённую картинку».

Есть также сценарий явного списка: «Книга, наушники, кошелек». SVG можно добавить из файла. Для импорта своей палитры используйте JSON с полями как в engine.js: backgroundLight, backgroundMid, backgroundDark, primary, secondary, ink, paper. Все значения — #RRGGBB. Цвета primary/secondary/ink запрещены в трёх фоновых слотах.

## Архитектура

- `assets/library.json` — каталог из 10 типов: книга, телефон, пазлы, монета, наушники, лампа, растение, папка, ручка, кошелёк. У каждого 4 настоящих SVG: S/L × главный/фоновый вариант (40 файлов).
- SVG получены штатным экспортом Figma из предоставленного файла с сохранением ID. Сохранены векторные контуры; растеризации и генерации новых объектов нет. Размер viewBox обрезан по геометрическим границам; контуры не перерисовывались.
- `engine.js` — палитры и словарь смысловых тегов. Подключается до app.js; используется редактором и тестами.
- `svg-safety.js` — общий фильтр атрибутов SVG: только поддерживаемые атрибуты и локальные ссылки, без внешних ресурсов и активного содержимого.
- `app.js` — модель композиции, импорт, редактор и сериализация SVG. Каждый экземпляр получает собственные ID; ссылки на градиенты и маски переназначаются вместе с ними. Экспорт убирает рамку выделения и сохраняет вложенные векторные группы.
- Палитра заменяет исходные семантические цветовые слоты, включая stroke и stop-color. Фоновая роль выбирает отдельный исходник, а не упрощает главный объект автоматически.
- Состояние композиции хранит только ссылки на каталог и трансформации. Исходные SVG не модифицируются.

## Допущения и ограничения

Два сценария разделены: явные названия выбирают только перечисленные объекты в порядке запроса; смысловые темы сопоставляются с существующими объектами через локальные правила. LLM не подключена. Неизвестный запрос не выдумывает изображение, а предлагает выбрать элементы вручную. Это ограниченный прототип, не универсальное понимание произвольных метафор. Компоновка использует несколько правил размещения и допускает дальнейшую ручную правку.

Размер S используется до ширины 1000, L — от 1000. При переключении относительное положение сохраняется. Три палитры воспроизводят исходные цветовые схемы библиотеки; фоновые элементы используют только фоновые слоты и белый.

На превью есть ненавязчивый водяной знак dobropalm. Происхождение исходной графики указано в ASSET-NOTICE.md. Экспорт SVG остаётся чистым для проверки редактируемости. Страница помечена noindex; это не ограничение доступа и не защита от копирования.

Сохранение/открытие проекта рассчитано на встроенную библиотеку. Пользовательские импортированные SVG доступны в текущей сессии; повторно импортируйте их после перезагрузки. Их произвольные цвета, не совпадающие с известными слотами, автоматически не классифицируются. Текст и SVG-эффекты не конвертируются в новые формы. Импорт ограничивает активные элементы и внешние ссылки; это прототип, не полноценный сервис для публичной загрузки недоверенных файлов.

Из исходных групп извлечено 52 SVG-группы; 40 являются предметными вариантами. Остальные — образцы фонов и цветовые таблицы, в предметный каталог они не включены. Число 20 трактуется как исходные иллюстрации/варианты, а не обещание 20 разных предметов: в предоставленной библиотеке определены 10 уникальных предметов.

## Проверка

`node --test tests/*.test.mjs` — подбор по именам и метафоре, неизвестный запрос, валидация палитр, наличие всех 40 реальных векторных файлов.

Дополнительно проверены в браузере: импорт, создание композиции, смена S/L и палитры, дублирование, скачивание SVG и проекта. Три экспортированных примера проверены как XML: уникальные ID, целые локальные ссылки, нет растра и рамки выделения. Не заявляется полная проверка всех комбинаций и всех браузеров.

## AI-инструменты

Codex: реализация, разбор экспортированных SVG, тесты и проверка интерфейса. Figma и Safari: штатный экспорт исходников. Генеративные изображения и сторонние библиотеки иллюстраций не использовались.

## Рефакторинг и дизайн

Редактор, подбор, импорты и безопасность проверялись отдельными агентами. Валидация проекта проверяет размеры как пары и правила фона; SVG-инстансы получают уникальные ASCII ID вместе с переназначением ссылок. Встроенная книга L использует производный светлый оттенок, который также меняется с палитрой.

Для интерфейса применён UI UX Pro Max из nextlevelbuilder/ui-ux-pro-max-skill; визуальный ориентир — рабочее пространство Higgsfield, без копирования бренда или медиа. Простые русские названия действий, дополнительные форматы скрыты. API и генеративные изображения не добавлялись.

Регрессионные проверки покрывают неизвестные и экранированные CSS URL, внешние href, обычные цвета и локальные градиенты с резервным цветом, валидные и некорректные JSON-проекты. Проверка не является доказательством поддержки всего стандарта SVG или всех просмотрщиков.

## Приёмка перед релизом 26 октября 2026

50 автоматических тестов и ручной браузерный прогон описаны в [QA.md](QA.md). Лимиты редактора совпадают с форматом сохранения: 100 объектов, координаты ±5000, проект до 1 МБ, палитра до 64 КБ, SVG до 2 МБ. Последний выбранный файл имеет приоритет; повторный выбор того же файла поддерживается. Управление заблокировано до загрузки библиотеки.

## Подбор композиции

Явный список поддерживает все 10 предметов, запятые, точку с запятой, перенос строки и союз «и». Повторённое название обозначает один предмет; количество экземпляров меняется дублированием. Недоступная часть разделённого списка сообщает об ошибке без потери текущей картинки. Декоративные объекты не добавляются. Длинные списки располагаются сеткой.

Смысловые правила покрывают обучение, идеи, цели/препятствия, сотрудничество, финансы, защиту, общение, отдых, порядок и развитие. Например, «Преодолеть преграды на пути к мечте» выбирает пазлы, растение и лампу. Это интерпретация ограниченного каталога, а не универсальное понимание языка; новые темы требуют расширения правил либо отдельного семантического/LLM-подбора.

## Разные экраны и управление

Адаптивная компоновка и выполненные проверки описаны в [RESPONSIVE.md](RESPONSIVE.md). Холст доступен с клавиатуры: выберите объект и сфокусируйте холст, затем используйте стрелки; Shift перемещает на 10 единиц. На сенсорном экране перетаскивание предмета отделено от прокрутки по пустому фону. Аппаратная проверка жестов на iOS/Android ещё требуется.

## Непрозрачность исходной монеты

В четырёх исходных вариантах монеты отсутствовала заливка боковой поверхности. Под оригинальными путями добавлена векторная подложка по внешнему силуэту: белая для основной роли, backgroundLight для фоновой. Исходные пути/цвета/детали сохранены. Подложка перекрашивается вместе с палитрой и экспортируется как вектор. Разработческий скрипт tools/repair_coin_opacity.py восстанавливает её из исходных контуров (fonttools/skia-pathops нужны только для повторного построения, не для запуска сайта). Другие36вариантов не менялись.

## Кэш статических файлов

После изменения CSS или JS запускайте `python3 tools/sync_static_versions.py` из папки редактора. HTML ссылается на ресурсы с SHA-256-префиксом содержимого; тест проверяет актуальность ссылок. Это предотвращает сочетание нового SVG-логотипа со старым CSS, где всем SVG в шапке задавались25px. Логотип также имеет собственные размеры и не сжимается flex-контейнером. Каталог и исходные SVG используют условную перепроверку HTTP-кэша при загрузке.

## Жесты на сенсорном экране

Начните жест одним пальцем на предмете: он перемещается. Добавьте второй палец на холст — вращайте пару для поворота, сближайте/разводите для масштаба. Выбранный предмет остаётся тем же; третий палец не перехватывает управление. После отпускания одного пальца перемещение продолжается без скачка. Отмена жеста освобождает оба указателя. Масштаб ограничен0.2–3, угол нормализован в−180…180°, непрерывный оборот возможен многократно. Фоновую прокрутку страницы начинайте вне предмета/рамки выделения.

Автотесты исполняют настоящие обработчики указателей и проверяют поворот/масштаб/переходы/отмену/сохранение. Они не заменяют аппаратную проверку Safari на iPhone/Android.
