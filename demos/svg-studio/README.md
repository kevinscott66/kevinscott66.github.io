# Сборка — SVG Studio

Локальный веб-прототип конструктора иллюстраций из библиотеки тестового задания. Реализация с помощью Codex.

## Запуск

Из этой папки выполните `python3 -m http.server 8768 --bind 127.0.0.1`, затем откройте http://127.0.0.1:8768 . Установка зависимостей и API-ключи не нужны. Файлы обрабатываются в браузере, сервер только раздаёт статику.

## Демонстрация

1. Введите «Рост знаний и новые идеи», нажмите «Собрать композицию».
2. Переключите размер на 1200 × 800: подгрузится детализация L. Выберите «Персик».
3. Перетаскивайте объекты; настройте поворот, масштаб, главную/фоновую роль и порядок слоёв. Объект можно дублировать или удалить.
4. Скачайте SVG, либо сохраните проект JSON для дальнейшего редактирования.
5. Примеры в `examples/`: learning, music, finance. Каждый представлен SVG и редактируемым проектом JSON. JSON можно открыть кнопкой «Открыть проект».

Есть также сценарий явного списка: «Книга, наушники, кошелек». SVG можно добавить из файла. Для импорта своей палитры используйте JSON с полями как в engine.js: backgroundLight, backgroundMid, backgroundDark, primary, secondary, ink, paper. Все значения — #RRGGBB. Цвета primary/secondary/ink запрещены в трёх фоновых слотах.

## Архитектура

- `assets/library.json` — каталог из 10 типов: книга, телефон, пазлы, монета, наушники, лампа, растение, папка, ручка, кошелёк. У каждого 4 настоящих SVG: S/L × главный/фоновый вариант (40 файлов).
- SVG получены штатным экспортом Figma из предоставленного файла с сохранением ID. Сохранены векторные контуры; растеризации и генерации новых объектов нет. Размер viewBox обрезан по геометрическим границам; контуры не перерисовывались.
- `engine.js` — палитры и словарь смысловых тегов. Подключается до app.js; используется редактором и тестами.
- `app.js` — модель композиции, импорт, редактор и сериализация SVG. Каждый экземпляр получает собственные ID; ссылки на градиенты и маски переназначаются вместе с ними. Экспорт убирает рамку выделения и сохраняет вложенные векторные группы.
- Палитра заменяет исходные семантические цветовые слоты, включая stroke и stop-color. Фоновая роль выбирает отдельный исходник, а не упрощает главный объект автоматически.
- Состояние композиции хранит только ссылки на каталог и трансформации. Исходные SVG не модифицируются.

## Допущения и ограничения

Подбор метафор основан на прозрачном словаре тегов и простом сопоставлении русских слов; LLM не подключена. Неизвестный запрос не выдумывает изображение, а предлагает выбрать элементы вручную. Это ограниченный прототип, не универсальное понимание произвольных метафор. Компоновка использует несколько правил размещения и допускает дальнейшую ручную правку.

Размер S используется до ширины 1000, L — от 1000. При переключении относительное положение сохраняется. Три палитры воспроизводят исходные цветовые схемы библиотеки; фоновые элементы используют только фоновые слоты и белый.

На превью есть водяной знак «DOBROPALM · ТЕСТОВОЕ» и указание происхождения графики. Экспорт SVG остаётся чистым для проверки редактируемости. Страница помечена noindex; это не ограничение доступа и не защита от копирования.

Сохранение/открытие проекта рассчитано на встроенную библиотеку. Пользовательские импортированные SVG доступны в текущей сессии; повторно импортируйте их после перезагрузки. Их произвольные цвета, не совпадающие с известными слотами, автоматически не классифицируются. Текст и SVG-эффекты не конвертируются в новые формы. Импорт ограничивает активные элементы и внешние ссылки; это прототип, не полноценный сервис для публичной загрузки недоверенных файлов.

Из исходных групп извлечено 52 SVG-группы; 40 являются предметными вариантами. Остальные — образцы фонов и цветовые таблицы, в предметный каталог они не включены. Число 20 трактуется как исходные иллюстрации/варианты, а не обещание 20 разных предметов: в предоставленной библиотеке определены 10 уникальных предметов.

## Проверка

`node --test tests/engine.test.mjs` — подбор по именам и метафоре, неизвестный запрос, валидация палитр, наличие всех 40 реальных векторных файлов.

Дополнительно проверены в браузере: импорт, создание композиции, смена S/L и палитры, дублирование, скачивание SVG и проекта. Три экспортированных примера проверены как XML: уникальные ID, целые локальные ссылки, нет растра и рамки выделения. Не заявляется полная проверка всех комбинаций и всех браузеров.

## AI-инструменты

Codex: реализация, разбор экспортированных SVG, тесты и проверка интерфейса. Figma и Safari: штатный экспорт исходников. Генеративные изображения и сторонние библиотеки иллюстраций не использовались.
