# Приёмка Слойры

Это сценарии проверки результата задания, а не отчёт о пройденных проверках. Для каждого прогона фиксируются адрес, версия, устройство и фактический результат. Локальная версия и опубликованная демонстрация проверяются отдельно.

| Требование | Действие в интерфейсе | Ожидаемый результат |
| --- | --- | --- |
| Понятное начало | Открыть редактор | Предсказуемый пример с книгой и лампой; выбранный предмет и доступные настройки видны. Автоматического наклона нет. |
| Подбор по теме | Ввести «Обучение», нажать «Собрать» | Книга и лампа; сообщение перечисляет подбор. Подсказка объясняет словарь тем. |
| Подбор по предметам | Ввести «Лампа слева, книга по центру, растение справа» | Три названных предмета в указанном порядке. |
| Граница словаря | Ввести незнакомую тему или незавершённое отношение «Книга слева от» | Понятное уточнение; прежняя композиция не меняется. Не подставляются случайные предметы. |
| Основной и фоновый варианты | Выбрать предмет на холсте или в списке, переключить вариант рисунка | Оба варианта доступны в панели настроек; переключение не подменяется изменением порядка слоёв. |
| Размер S/L | У книги, лампы и растения переключить исходник S/L | Меняется исходный SVG, сохраняются его пропорции. Масштаб и размер холста подписаны отдельно. |
| Относительные размеры | Собрать несколько разных предметов, сменить холст, сохранить и открыть JSON, скачать SVG | Исходные предметы не нормализуются в одинаковые квадраты. Относительный масштаб и пропорции воспроизводятся после открытия и в экспорте. |
| Ручное редактирование | Переместить, повернуть и масштабировать предмет; скопировать и удалить копию | Меняется выбранный предмет. Угол рамки сохраняет пропорции. Наклон появляется только по действию пользователя. |
| Слои | Перетащить строку списка или использовать «Вперёд / Назад» | Верхняя строка перекрывает нижние; выбор остаётся понятным. |
| Палитры | Сменить встроенную палитру, затем загрузить допустимый JSON | Перекрашиваются предметы и фон; конфликтующие цвета фона не принимаются без объяснения. |
| Импорт | Открыть «Дополнительно», добавить SVG | Предмет появляется в библиотеке; неподдерживаемый файл даёт понятную ошибку. |
| Сохранение и экспорт | Сохранить проект, открыть его; скачать SVG | JSON воспроизводит встроенные предметы, варианты и трансформации. SVG остаётся векторным, без рамок выделения и водяного знака превью. |
| Узкий экран и клавиатура | Проверить 320–390 px, планшет и настольный экран; пройти Tab | Нет горизонтального прокручивания страницы; действия, настройки и подписи доступны; фокус виден. На телефоне настройки находятся перед библиотекой под холстом. |
| Сенсорный ввод | На физических iPhone и Android переместить, масштабировать и повернуть выбранный предмет | Жесты работают без случайного выбора другого предмета; результат можно сохранить. Эмуляция не заменяет эту проверку. |
| Права и обработка файлов | Открыть ссылки в подвале | Объяснены локальная обработка файлов и отдельные права на графику. Экспорт не объявлен разрешением на коммерческое использование. |

Подбор ограничен локальными названиями, темами и правилами расположения. Успех этих сценариев не подтверждает понимание произвольного русского текста. Перечень ограничений и форматов — в [README](../README.md); права на графику — в [ASSET-NOTICE](../ASSET-NOTICE.md).
