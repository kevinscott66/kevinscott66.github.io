# Проверка Слойры — 1 ноября 2026

Состояние: локальные изменения, без публикации и синхронизации с зеркалом портфолио. Основные сценарии — [чек-лист приёмки](acceptance.md).

## Что исправлено

- Исходники S/L выбираются для каждого объекта; выбор не зависит от холста и сохраняется в JSON.
- Главный/фоновый вариант открыт в инспекторе и отделён от порядка слоёв.
- Встроенные иллюстрации используют общий масштаб исходных координат. Рамка, ручки и проверка попадания следуют фактической геометрии.
- Пользовательский SVG не меняет масштаб встроенных иллюстраций. При отсутствии viewBox используются корректные абсолютные размеры в пикселях; непригодный файл отклоняется до добавления в библиотеку.
- Старые JSON сохраняют прежний квадратный viewport и выбор S/L по сохранённому холсту. При явной смене S/L объект переходит на новую геометрию. Это совместимость, а не изменение старого документа без предупреждения.
- Автоматический наклон убран. После сборки показаны выбранные предметы и принцип словарного подбора.
- Подписи сохранения и экспорта указывают формат; дополнены подсказки, метаданные и адаптивные правила.

## Проверки и пределы результата

- Два прохода логики/интерфейса и отдельная статическая проверка безопасности тремя агентами; заключительный независимый проход логики не выявил новых существенных дефектов.
- 195 Node-тестов прошли, включая сохранение S/L, старые JSON, рамку/геометрию, стабильность встроенных размеров после импорта и SVG без viewBox. `git diff --check` без ошибок.
- В браузере проверены начальная композиция, явный список из трёх предметов, нулевой начальный поворот, S/L, фоновый вариант, копирование/удаление и сохранение композиции при неподдерживаемом запросе. Настройки визуально просмотрены при 1280×736.
- Мобильная ширина через browser viewport API не применилась: фактическая ширина осталась 1280. CSS проверен по коду, но просмотр при 320/390 и жесты на физических устройствах **не подтверждены**. Изображения текущей проверки отображены в сессии; отдельный сохранённый комплект скриншотов не создан.
- Статический security scan не нашёл подтверждённых уязвимостей в изученных путях SVG/JSON, импорта, экспорта, сетевых обращений и CI. Это частичное покрытие, без adversarial browser rendering; отсутствие любых уязвимостей не доказано. Отчёт хранится локально вне публичного репозитория в журнале Codex Security.
- Для демонстрационного редактора сохранён прежний `noindex`. Метаданные улучшены, но это не запуск поискового продвижения. Индексируемый маркетинговый кейс и коммерческие права на иллюстрации — отдельные решения.
