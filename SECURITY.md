# Security Policy

This repository holds the source of the static site published at
[dobropalm.tech](https://dobropalm.tech). It has no backend, no user accounts
and no data collection: the site is plain HTML and CSS served by GitHub Pages
behind Cloudflare.

## Reporting

If you find a problem here — a broken security header, a mixed-content issue,
a subdomain that no longer points where it should, or anything that could be
used to misrepresent this domain — report it to:

- **hello@dobropalm.tech**
- Telegram: [@dobropalm](https://t.me/dobropalm)

Please do not open a public issue for anything that could be abused before it
is fixed.

## What to expect

- acknowledgement within 72 hours
- a fix or a clear explanation of why it is not one, within 90 days
- credit in the fix commit if you want it

## Scope

In scope: this repository and the content served at `dobropalm.tech`.

Out of scope: the projects linked from the site — they have their own security
policies in their own repositories.
