DOBROPALM Agent — a personal AI ecosystem

Architecture · Agent orchestration · iOS · 3D

A Russian-first personal assistant with twelve specialist roles sharing a Telegram bot, a native iPhone app, browser chat and a virtual office with dedicated role workstations. Shared conversation history, scoped memory, delegation and audited tools connect the interfaces; permissions and approval gates govern execution.

Browser and iPhone conversations support voice input and spoken replies, shared history and in-chat approvals. Active development adds a 2D/3D office, cross-client role routing and a scoped read-only GitHub MCP adapter. Office changes are available on the development branch; app releases and account setup remain separate steps. Personal banking execution remains planned.

02Open source

AirChat — messenger on an untrusted server

Mobile · Networking · Cryptography

A messenger with a seed-phrase identity: no phone number or sign-up. Encrypted account sync restores conversations on another device; servers still see routing and sync metadata. Posts shared by public link are unencrypted. The browser supports internet connectivity and WebRTC; native builds add LAN messaging. Wi-Fi Direct mesh remains disabled in the current source, and LoRa/HF are not enabled. Browser key storage offers weaker protection than native secure storage; sync and calls require connectivity.

05In production

DeLabs — crypto & AI research platform

Product · Full stack · Editorial data pipelines

A Russian-language research site that brings daily briefs, activity guides, airdrop tracking and token unlocks into one searchable project catalog. Public source links sit beside the reporting; editorial revisions survive data refreshes, and a protected editor keeps corrections separate from source snapshots.

As of 24 September 2026: 536 research briefs, 181 activity guides and 315 project profiles, with 22 airdrop programs tracked and 132 token unlock entries. Built with Next.js, React and TypeScript, with server-rendered pages, locally served project logos, RSS and a searchable archive.

Capabilities

Whole problems,
not tickets.

Discovery through deployment, and the operations that come after it.

Agent systems

Multi-agent architectures with defined roles, budgets and escalation paths. Autonomy that is auditable, reversible, and bounded by permissions rather than by hope.

Security & permissions

Threat modelling, least-privilege design, row-level security, secret hygiene and history auditing. Defaults that deny, and logs that let you prove what actually happened.

Resilient networking

P2P and mesh transports, offline queues, conflict resolution, graceful degradation. Designed for a network assumed to fail.

Cross-platform apps

Native iPhone apps with SwiftUI, shared mobile and web apps with React Native, and PWAs packaged with Capacitor and Tauri. Release channels and platform limits are designed into the delivery workflow.

Legacy migration

Strangler-pattern rewrites of systems that cannot stop running. Incremental replacement with a working rollback at every step.

Operational tooling

Dashboards, approval queues, health checks and deployment pipelines — the unglamorous layer that decides whether a system is genuinely operable, or merely deployed.

Method

Four commitments
on every engagement.

01

Failure is the design brief

The interesting question is never the happy path. I start from the network dropping, the token leaking, the agent going wrong — and design so the answer is a degraded but safe state, not an outage or a breach.

02

Ownership, end to end

Architecture, implementation, tests, deployment and the operational tooling afterwards. No hand-off gap where a decision quietly gets lost between people.

03

Ship in slices

Something real in production early, then grown. Migrations happen behind stable interfaces, so the running system is never held hostage to the rewrite.

04

Readable systems

Code, docs and history written for whoever inherits them. Every project I hand over is one another engineer can pick up without me in the room.
